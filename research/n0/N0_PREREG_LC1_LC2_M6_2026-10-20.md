- LONG-BRIDGE-GEOM V1 (SHA `6a4bbd9e50dcffe598aee9ac36de30ef9e098c5ba768e9ed174ce47258dd4fb4`), auditado PASS por Claude.

## 1. Nota de contaminación previa

Este dominio **no es un holdout totalmente virgen** para las estadísticas LC1/LC2.
Antes de este preregistro se inspeccionaron las 52 palabras con `rho=20` del censo m=6; entre ellas se observó post hoc que 44 tenían `W_core=5` y 8 tenían `W_core=4, W_ext=1` para el puente extremo considerado.

Lo que **no** se ha censado antes es el conjunto completo de todos los puentes extremos más cercanos de todas las `2^37` palabras.
Por tanto, un resultado positivo se etiquetará como **Observación exhaustiva preregistrada sobre el dominio completo, no holdout virgen**; no como prueba universal.

## 2. Dominio exacto

Fijar `m=6`, `L=13`, inicios de ventana `0..24`, palabra binaria de largo 37.

Enumerar **cada** entero

`w = 0,1,...,2^37-1`

exactamente una vez, con bit `j` de `w` igual a `x_j`.

Para cada palabra calcular directamente desde DEF-CORE:

1. `S_0,...,S_24`;
2. centros `y_i=x_{i+6}` y clases `C_i=(S_i,y_i)`;
3. `S_min`, `S_max`, `R=S_max-S_min`, `delta=13-R`;
4. todos los índices de mínimo y máximo global;
5. `n = min |a-c|` sobre todos los pares mínimo–máximo;
6. `b=n-R`.

Después considerar **cada par extremo más cercano** `{a,c}` tal que:

- uno de `a,c` es mínimo global y el otro máximo global;
- `|a-c|=n`.

Poner `u=min(a,c)`, `v=max(a,c)`. No se elige un par conveniente si hay varios: **se prueban todos**.

Para cada par, definir:

- `rho_core = # { C_i : u <= i <= v }`;
- `W_core = (n+1)-rho_core`;
- `E_ext = 24-n`;
- `N_ext = # { clases distintas fuera de [u,v] que no aparecen en el core }`;
- `W_ext = E_ext-N_ext`.

El sector de prueba es:

`1 <= delta`, `2*delta <= 7`, `b >= 11`.

Esto es exactamente el sector no trivial de puente largo para m=6.

## 3. Predicciones

### P1 — LC1(m=6), CON RIESGO

Para **todo** par del sector:

`W_core >= 4`.

Equivalente a `I_core <= b-4` por `W_core=b-I_core`.

**Falsador exacto:** una palabra de 37 bits y un par extremo más cercano del sector con `W_core <= 3`.

Si aparece, conservar el primer falsador en orden `(w,u,v)` y continuar el censo si el presupuesto lo permite.

### P2 — LC2(m=6), CON RIESGO

Para **todo** par del sector:

`W_core = 4  =>  W_ext >= 1`.

**Falsador exacto:** una palabra y par del sector con `W_core=4` y `W_ext=0`.

### P3 — control positivo de igualdad, SIN RIESGO / ya visto

Debe aparecer al menos un par del sector con

`W_core=4` y `W_ext=1`.

Este control no es evidencia nueva: ya existen ejemplos dentro de las 52 palabras `rho=20` inspeccionadas post hoc. Si el programa no encuentra ninguno, se considera **gate rojo de implementación** y P1/P2 no se interpretan.

### P4 — identidad de control, SIN RIESGO

Para cada par procesado verificar directamente:

`W_total = W_core + W_ext`,

donde `W_total=25-rho` y `rho` se calcula desde las clases de toda la palabra.

Una sola falla invalida la corrida.

## 4. Variabilidad / posibilidad de falsación

- P1 puede fallar porque `W_core` es una cantidad variable y LC1 no está demostrada.
- P2 puede fallar porque existen casos reales con `W_core=4`; por tanto su antecedente no es vacío.
- Ya se conocen miles de casos de igualdad `W_core=m-2` para m<=5 y ejemplos en m=6; LC2 no es vacua.

No se calcularán tasas de significancia: es un dominio finito exhaustivo, no una muestra estadística.

## 7. Reglas de decisión

- Si P1 falla: `LC1 universal` sigue **Abierto** y la versión fuerte sugerida por el censo queda **Refutada en m=6**; preservar y verificar a mano el primer testigo.
- Si P1 pasa: `LC1(m=6)` queda como **Observación exhaustiva preregistrada, no holdout virgen**. LC1 universal sigue **Abierto**.
- Si P2 falla: congelar el primer par con `W_core=4,W_ext=0`; LC2 universal queda **Refutado** tras verificación exacta independiente del testigo.
- Si P2 pasa: `LC2(m=6)` queda como **Observación exhaustiva preregistrada, no holdout virgen**. LC2 universal sigue **Abierto**.
- P3 ausente o P4 fallando: **gate rojo**, no interpretar P1/P2.

Una futura segunda implementación independiente podría promover los resultados finitos de m=6 a **Certificado exacto**, pero no es requisito para continuar la prueba en papel.

## 8. Implica para la cota maestra

Este censo **no demuestra** el teorema universal. Su función es intentar matar LC1/LC2 en un dominio mucho mayor antes de invertir en la prueba.

`LC1 ∧ LC2 => W >= m-1 => rho <= 3m+2`

en la rama de puente largo.
